Privacy · updated 6 September 2026

Your layouts stay in your browser

Session Layout Capsule has no accounts, analytics, ads, tracking pixels, or remote database.

What the app stores

The app stores your layouts in browser IndexedDB. The service worker caches app files for offline use. Normal use sends requests only to this site.

What you choose to share

A JSON export, handoff link, or QR code contains your layout data. Anyone with that file or link can read it. Do not put passwords, license keys, or private credentials in a layout.

How to delete data

Delete one layout from its saved card. To remove every layout, clear site data for this domain in your browser settings. Export a JSON backup first if you need one.

External links

The app opens a saved web link only when you choose it. The destination then applies its own privacy terms.

Questions

Read the public source repository or open an issue there.
